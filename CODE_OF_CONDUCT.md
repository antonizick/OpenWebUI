# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). The full text is at that link; it is not reproduced here.

In short: be respectful and welcoming, accept constructive feedback, focus on what is best for the project, and do not harass or discriminate. Report concerns to the repository owner.
